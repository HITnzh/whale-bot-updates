# 群聊身份识别

日常配置、身份命令和验证方法统一见根目录 [使用说明.txt](../../使用说明.txt) 第4节。

主人身份仅由当前平台事件的发送者 UID 精确匹配 AstrBot 的 `admins_id` 决定。昵称、登记关系、群管理员头衔、被 @ 者、引用内容和长期记忆都不会授予主人身份。身份登记按平台隔离，原有登记数据保持使用。
非主人的登记称呼或关系含主人专属称呼时，身份自查与查询结果按普通群友展示，不修改原始登记数据。

每次主模型请求都会附加当前发送者的固定身份判定。`inject_template` 仅控制补充介绍，模板为空、缺少身份占位符或格式无效时，仍保留固定判定；`inject_for_master` 只控制主人的补充介绍。对普通群友的查询提示使用中性称呼，主人查询不会擅自把管理员列表首项当作本群主人并 @ 出来。

| 配置 | 作用 |
| --- | --- |
| `master_title` | 已验证主人的专属称呼，不授予身份 |
| `inject_for_master` | 是否为主人附加自定义模板介绍，不关闭固定身份判定 |
| `treat_unknown_as` | 未登记群友的补充描述，不改变主人判定 |
| `inject_template` | 补充介绍模板，支持 `{sender_id}`、`{sender_name}`、`{group_id}`、`{identity_line}` |

身份判定与工具权限在代码中校验；自然语言称呼仍由模型生成。固定判定用于约束模型，不对所有输出机械删除“主人”，以保留正常的第三人称讨论。

离线验证：在项目根目录运行 `.\python\python.exe -m unittest discover -s tests -p 'test_whale_identity.py' -v`。测试使用虚构身份，不调用模型或发送 QQ。
