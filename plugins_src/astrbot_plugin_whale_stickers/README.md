# 鲸鱼娘自主表情

用户操作统一见根目录 [使用说明.txt](../../使用说明.txt) 第3节。

主模型先调用 get_sticker_candidates 按标签查询少量图片，再读描述选择具体ID，调用 send_sticker。普通聊天仅提供标签和简短规则，不传入全部图片或完整目录，也不额外调用分类、视觉模型。需要发图时会增加主模型的工具交互。

- 由模型决定是否配图，没有第二次随机否决；默认同时满足3轮对话与60秒的会话冷却。
- 仅精确标签和明确别名匹配，不用子串或字符相似度猜情绪。查候选不等于已发图。
- 每轮最多一张。文字可以配表情，语音与表情互斥，流式模式不启用表情工具。
- 仅发送有效的目录内图片。发送失败或取消不记录已发送状态，不开始冷却，也不自动重试。
- 成功工具结果包含实际图片ID、描述和标签，随工具调用进入当前对话历史。插件另在当前会话内保留最近5张的短记录，下轮最多注入3条；重载会清空这份内存记录，已有工具历史仍以框架保存情况为准。
- 兼容尾部标记中的具体图片ID，以及只对应一张图的标签；多个候选的标签不擅自代选。未知、过长或未闭合标记会被清理，不当作发送指令。

配置见 _conf_schema.json：enabled、cooldown_replies、cooldown_seconds、candidate_limit。候选数量默认4、范围1～5；WHALE_STICKER_PROB不参与发送决策。表情目录可由 WHALE_STICKER_DIR 指定。

素材目录的 index.json 使用 file 和 tags，稳定ID默认是文件名去扩展名，也可显式填写 id。描述字段 desc 用于选择图片；usage、avoid、intensity、visible_text 是可选扩展。图中文字没有经过自动识别，visible_text为空表示未核对，不代表图片上没有文字。图片的来源、作者和许可数据保持保留，/表情作者可查看署名。

目录模块 catalog.py 会校验图片路径和文件内容，不接受任意路径、网址、预览拼图或目录外链接。

离线验证使用根目录 tests/test_whale_sticker_catalog.py、tests/test_whale_stickers.py 和语音互斥测试；不调用收费模型或QQ。
