# 大肥鱼人设

日常维护只修改本目录中的两份设定：

| 文件 | 用途 |
| --- | --- |
| [system_prompt.txt](system_prompt.txt) | 主设定：身份、性格、表达风格、记忆、群聊、唱歌与认主规则。 |
| [safety_addendum.txt](safety_addendum.txt) | 补充边界：AI 身份、互动分寸、如实使用工具。 |

## 加载与生效

正常启动时，根目录的 `start.bat` 会执行 `configure.py`。它默认读取 `system_prompt.txt`，再追加 `safety_addendum.txt` 和从表情包索引生成的规则，写入数据库中的“鲸鱼娘”人设。

如果环境变量 `PERSONA_FILE` 指定了其他文件，主设定会改读该文件；补充边界仍读取本目录的 `safety_addendum.txt`。

修改文本不会自动刷新正在运行的机器人。保存后按正常流程停止并重新启动，使配置写入并由机器人重新加载。不要只在 WebUI 修改人设而忽略源文件，下次正常启动会按文件重新写入。

本 README 不会拼接进模型提示词。身份插件另外注入的当前用户身份，也不由本目录维护。
