# 五个新能力 · 安装说明（自动更新已带插件代码）

这次更新会通过自动更新装上：认主、天气、LivingMemory、主动消息，并打开 DeepSeek 联网搜索。  
**密钥不会进更新包**，下面几步要在你电脑上做一次。

## 0. 拉更新并重启

1. 关掉黑窗口，或双击 `停止.bat`
2. 双击 `立即更新.bat`（或直接 `启动鲸鱼娘.bat`，启动前也会更新）
3. 日志里应出现：
   - `plugin installed: astrbot_plugin_identity`
   - `plugin installed: astrbot_plugin_weather`
   - `plugin installed: astrbot_plugin_livingmemory`
   - `plugin installed: astrbot_plugin_proactive_chat`
   - `web_search=deepseek`

## 1. 联网搜索（DeepSeek Search）

一般**不用你点**：`configure.py` 会用 `secrets.env` 里的 `DEEPSEEK_API_KEY` 自动打开。  
若没生效：浏览器打开 http://localhost:6185 → 配置文件 → AI → 能力 → 网页搜索  
- 启用网页搜索  
- 提供商选 **deepseek**  
- Key 填和 DeepSeek 对话同一个 Key → 保存

试一句：「先搜索再回答：今天有什么科技新闻」

## 2. 认主（astrbot_plugin_identity）

QQ **官方机器人看不到数字 QQ 号**，用的是 **openid**。

1. 私聊她，发送：`/sid`  
2. 她会回一串 UMO，类似：  
   `default_1905913599:FriendMessage:xxxxxxxx`  
   **最后一段 `xxxxxxxx` 就是你的 openid**
3. 任选其一：
   - 在 `secrets.env` 加一行：`OWNER_OPENID=你的openid`，然后重启  
   - 或 WebUI → 配置 → `admins_id` 里加上这个 openid（保留原来的 `astrbot`）→ 保存 → 重启

群友默认当「朋友」聊，不会乱认主。

## 3. 天气（免 Key）

直接问：「北京天气怎么样」或发 `/天气 上海`  
默认用 wttr.in，不用申请 Key。

## 4. LivingMemory（长期记忆）· 需要免费 Embedding

DeepSeek **没有**嵌入模型，推荐 [硅基流动 SiliconFlow](https://cloud.siliconflow.cn/) 免费额度：

1. 注册并创建 API Key  
2. 在 `secrets.env` 加一行（不要发给别人）：  
   `SILICONFLOW_API_KEY=你的硅基Key`  
3. 重启。日志应有：`embedding=siliconflow_embedding (SiliconFlow BAAI/bge-m3)`  
4. WebUI 也可手动：服务提供商 → Embedding → 新增 OpenAI Embedding  
   - API Base：`https://api.siliconflow.cn/v1`  
   - 模型：`BAAI/bge-m3`  
   - 维度：1024（或 auto）  
   然后在插件 LivingMemory 配置里，Embedding 模型 ID 填 `siliconflow_embedding`（或你起的 id）

没配 Embedding 时，插件会装上但记忆召回不可用。

## 5. 主动消息（Proactive Chat）

1. 私聊发：`/sid`，复制完整 UMO  
2. WebUI → 插件 → **主动消息 (Proactive Chat)** → 配置  
   - 私聊会话 UMO 列表：粘贴刚才的 UMO（可多条）  
   - 建议打开「自动主动消息」，等待时间可先设 30～60 分钟  
   - 设好免打扰时段（比如 23:00–08:00）  
3. 保存并重载插件 / 重启

**注意**：机器人平台名必须和 UMO 第一段一致（常见是 `default_1905913599`）。  
群里要主动发言，还要在 QQ 群机器人设置里打开「主动在群聊内发言」。

## secrets.env 示例（本地文件，勿转发）

```
DEEPSEEK_API_KEY=你原来的Key
OWNER_OPENID=从/sid拿到的openid
SILICONFLOW_API_KEY=硅基流动Key
```

## 出问题就截图

- 插件装上但工具不灵：确认人设「鲸鱼娘」的 tools 不是空列表（这次 configure 会设成允许全部工具）  
- 认主不灵：确认填的是 **openid** 不是 QQ 号  
- 主动消息不发：UMO 是否完整、免打扰是否挡着、黑窗口是否还在跑
